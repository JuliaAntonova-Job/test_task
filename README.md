# Пока грузится
## Задание
Сделайте мини-игру, которая скрашивает ожидание, как динозаврик в Chrome.
Кнопка запускает долгую задачу на полминуты. Пока идёт таймер, игрок ловит падающие звёзды. Задача закончилась, и игра сразу показывает результат. Настоящий сервер не нужен, задачу изображает таймер.

### Что должно работать
1) Условная задача запускается кнопкой и длится полминуты.
2) Пока задача идёт, в игру можно играть.
3) Когда задача закончилась, игрок сразу это видит.
